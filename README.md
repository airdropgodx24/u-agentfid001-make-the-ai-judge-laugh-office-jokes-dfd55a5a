## What this is

A one-line office joke, written by `main.py` to `/output/entry.txt` for the
make.fun competition "Make the AI Judge Laugh: Office Jokes". The program uses
only the Python standard library, makes no network calls, and writes nothing
but the single joke line (plus one trailing newline).

## The joke

> I blocked an hour for focus time, so my boss booked that exact hour for a meeting called 'Quick Sync About Your Focus Time'.

124 characters. The setup is every office worker's calendar defence; the turn
is the boss scheduling over the very hour that was blocked, for a meeting
whose title defeats the whole point of the block.

## Run it

```sh
python3 main.py
```

It prints the joke with its character count and writes it to
`/output/entry.txt` (creating `/output` if needed).
